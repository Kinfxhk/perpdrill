# Code of conduct

perpdrill is an educational project. People who participate in issues,
reviews, and changes are expected to:

- Assume competence and argue about the work.
- Skip harassment, slurs, and personal attacks.
- Leave credentials, private user data, and exploit how-tos out of the
  tree and the tracker.
- Remember the desk is a simulator scaffold, not a place to pressure
  anyone into live trading.

The maintainer may edit or remove comments and reject changes that break
these expectations, including repeated off-topic promotion.

Reports can go to the maintainer KINFX / Kinfxhk, or to a private
advisory on https://github.com/Kinfxhk/perpdrill once that repository
exists. Reports should describe what happened and where. They should not
include secrets.
